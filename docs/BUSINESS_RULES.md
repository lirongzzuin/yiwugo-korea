# YiwuGo Korea - Business Rules

## 1. 주문 상태 흐름

```
주문접수 (PENDING)
  │
  ▼
결제완료 (PAID)
  │
  ▼
현지수거중 (COLLECTING)
  │
  ▼
검수중 (INSPECTING)
  │
  ├──▶ 불량 발견 → 교환요청 (EXCHANGE_REQUESTED) → 교환완료 → 검수중
  │
  ▼
포장완료 (PACKED)
  │
  ▼
국제운송중 (SHIPPING_INTERNATIONAL)
  │
  ├── 항공: 3~5일
  └── 해상: 10~15일
  │
  ▼
통관중 (CUSTOMS_CLEARANCE)
  │
  ├──▶ 통관 보류 (CUSTOMS_HOLD) → 서류 보완 → 통관중
  │
  ▼
국내배송중 (SHIPPING_DOMESTIC)
  │
  ▼
배송완료 (DELIVERED)
  │
  ▼
구매확정 (CONFIRMED) — 배송완료 후 7일 자동 확정
```

### 취소 가능 구간

| 상태 | 취소 가능 | 환불 비율 | 비고 |
|------|----------|----------|------|
| PENDING | O | 100% | 즉시 취소 |
| PAID (24시간 이내) | O | 100% | 즉시 환불 |
| PAID (24시간 이후) | O | 100% | 수거 전에 한해 |
| COLLECTING | △ | 90% | 수거 수수료 10% 공제 |
| INSPECTING | △ | 80% | 검수 수수료 + 현지 반품비 |
| PACKED 이후 | X | - | 취소 불가, 수령 후 반품만 가능 |

## 2. 수수료 계산 방식

### 서비스 수수료 (구매 대행 수수료)

| 결제 금액 (원화 기준) | 수수료율 |
|----------------------|---------|
| 50만원 미만 | 10% |
| 50만원 ~ 200만원 | 8% |
| 200만원 ~ 500만원 | 6% |
| 500만원 ~ 1,000만원 | 5% |
| 1,000만원 이상 | 별도 협의 |

### 검수 수수료
- 기본 검수 (수량/외관 확인): 무료
- 상세 검수 (기능 테스트, 치수 측정): 건당 500원
- 사진 검수 (개별 사진 촬영): 건당 300원

### 합포장 수수료
- 2개 상점 합포장: 무료
- 3~5개 상점: 건당 2,000원
- 6개 이상: 건당 3,000원

## 3. 환율 적용 정책

### 기본 원칙
- 상품 가격: 중국 위안(CNY) 기준
- 결제 통화: 한국 원(KRW)
- 환율 소스: 하나은행 전신환 매도율 기준

### 환율 적용 시점
- **상품 페이지 표시**: 실시간 환율 (1분 간격 갱신)
- **장바구니 표시**: 실시간 환율 (페이지 로드 시점)
- **결제 확정**: 결제 시점 환율 고정 (10분 유효)
- **환율 보정**: +2% (환율 변동 리스크 버퍼)

### 환율 공식
```
원화 가격 = CNY 가격 × (기준 환율 × 1.02)
```

### 환율 보호
- 결제 후 환율이 5% 이상 변동 시: 회사 부담 (추가 청구 없음)
- 환율 급등/급락 시 일시적 주문 중단 가능

## 4. 쿠폰/적립금 규칙

### 쿠폰
- **발급 유형**: 신규 가입, 이벤트, 등급 혜택, 관리자 수동 발급
- **할인 유형**: 정률 (%), 정액 (원)
- **최소 주문 금액**: 쿠폰별 설정 (기본 30,000원)
- **최대 할인 금액**: 정률 쿠폰은 최대 할인 한도 설정 필수
- **사용 제한**: 1주문 1쿠폰, 배송비에는 적용 불가
- **유효기간**: 발급일로부터 30일 (이벤트 쿠폰은 별도)
- **중복 사용**: 불가 (적립금과는 동시 사용 가능)

### 적립금
- **적립 방법**:
  - 구매 확정: 결제 금액의 1%
  - 리뷰 작성: 텍스트 리뷰 200P, 포토 리뷰 500P
  - 이벤트 참여: 이벤트별 상이
  - 추천인 등록: 추천인/피추천인 각 1,000P
- **사용 규칙**:
  - 최소 사용: 1,000P (= 1,000원)
  - 최대 사용: 결제 금액의 30%
  - 배송비에는 사용 불가
- **유효기간**: 적립일로부터 1년
- **소멸 안내**: 만료 30일 전 알림 발송

## 5. 환불 정책

### 환불 사유별 처리

| 사유 | 환불 비율 | 배송비 | 처리 기간 |
|------|----------|--------|----------|
| 검수 불량 (수거 전) | 100% | 무료 | 3~5 영업일 |
| 상품 불일치 | 100% | 무료 | 5~7 영업일 |
| 배송 중 파손 | 100% | 무료 | 5~10 영업일 |
| 단순 변심 (수거 전) | 100% | 무료 | 3~5 영업일 |
| 단순 변심 (국제배송 전) | 90% | 현지 반품비 고객 부담 | 7~10 영업일 |
| 단순 변심 (수령 후) | 80% | 국제배송비 왕복 고객 부담 | 14~21 영업일 |

### 환불 불가 항목
- 커스텀/주문제작 상품
- 수령 후 7일 경과 (구매 확정 이후)
- 고객 귀책 사유 파손
- 위생 상품 개봉 후

### 환불 절차
1. 환불 신청 접수 (앱/웹)
2. 사진/영상 증빙 제출 (파손/불량 시)
3. 검토 및 승인 (1~2 영업일)
4. 반품 배송 (필요 시)
5. 환불 처리 (카드 취소 3~5 영업일 / 계좌 입금 1~2 영업일)

## 6. 배송비 계산 규칙

### 국제 배송비

#### 항공 운송
| 중량 | 단가 (kg당) |
|------|------------|
| 0.5kg 미만 | 기본료 8,000원 |
| 0.5~5kg | 6,000원/kg |
| 5~10kg | 5,500원/kg |
| 10~30kg | 5,000원/kg |
| 30kg 이상 | 별도 견적 |

#### 해상 운송
| 부피 | 단가 (CBM당) |
|------|-------------|
| 0.1 CBM 미만 | 기본료 50,000원 |
| 0.1~0.5 CBM | 200,000원/CBM |
| 0.5~1 CBM | 180,000원/CBM |
| 1 CBM 이상 | 별도 견적 |

### 적용 기준
- **실중량 vs 부피중량**: 두 값 중 큰 값 적용
- **부피중량 공식**: 가로(cm) x 세로(cm) x 높이(cm) / 6,000 = kg
- **합포장 할인**: 합포장 시 총 중량 기준 단가 적용 (개별 발송보다 저렴)

### 국내 배송비
- CJ대한통운 기본 배송비: 3,000원
- 도서산간 추가: +3,000원
- 제주도 추가: +5,000원

### 무료 배송 기준
- 상품 금액 100만원 이상: 항공 배송비 무료
- 상품 금액 300만원 이상: 항공/해상 선택 무료
- 이벤트 기간: 별도 무료 배송 조건 적용 가능

## 7. 통관 기준

### 개인 통관 (개인 사용 목적)
- **면세 한도**: 미화 $150 이하 (미국발 $200 이하)
- **과세 기준**: 상품 가격 + 국제 배송비 + 보험료 = 과세 가격
- **관세율**: 품목별 상이 (의류 13%, 전자제품 8%, 생활용품 8% 등)
- **부가세**: 과세 가격 + 관세의 10%
- **필수 서류**: 개인통관고유부호

### 사업자 통관
- **모든 금액 과세** (면세 한도 없음)
- **관세 + 부가세(10%)** 부과
- **필수 서류**: 사업자등록증, 수입신고서
- **부가세 환급**: 매입세액 공제 가능

### 품목별 특이사항

| 품목 | 관세율 | 추가 요건 |
|------|--------|----------|
| 의류/섬유 | 13% | KC 인증 (아동복) |
| 전자제품 | 0~8% | KC 인증, 전파인증 |
| 화장품 | 6.5% | 식약처 수입 신고 |
| 식품 | 8~50% | 식품 수입 신고, 검역 |
| 장난감 | 8% | KC 인증 (어린이용) |
| 의료기기 | 8% | 식약처 허가 |

### 수입 금지/제한 품목
- 위조 브랜드 상품
- 마약류, 향정신성 의약품
- 총기, 도검류
- 멸종 위기 동식물 관련 제품
- 음란물
- 식물/종자 (검역 필요)
- 육류/유제품 (검역 필요)

### 통관 지연 시 대응
1. 관세사 자동 배정
2. 추가 서류 요청 시 이용자에게 알림
3. 서류 제출 기한: 요청 후 5영업일
4. 기한 내 미제출 시 반송 처리 (비용 이용자 부담)
