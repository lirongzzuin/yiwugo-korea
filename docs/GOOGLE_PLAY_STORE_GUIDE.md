# Google Play Store 배포 가이드

이우고 코리아 Android 앱을 Google Play Store에 배포하는 전체 과정을 안내합니다.

---

## 사전 준비

### 1. 필수 계정
- **Google Play Console 개발자 계정** ($25 일회성 등록비)
  - https://play.google.com/console 에서 등록
  - 실명, 주소, 연��처 필요
  - 본인 인증 완료까지 1-3일 소요

### 2. 필수 도구
```bash
# EAS CLI 설치
npm install -g eas-cli

# Expo 로그인
eas login
```

### 3. 필수 에셋
- `apps/mobile/assets/icon.png` (1024x1024)
- `apps/mobile/assets/adaptive-icon.png` (1024x1024)
- `apps/mobile/assets/splash.png` (1284x2778)
- 스토어 스크린샷 최소 2장 (핸드폰 해상도)
- 그래픽 이미지 1장 (1024x500)

## Step 1: EAS 프로젝트 초기화

```bash
cd apps/mobile

# EAS 프로젝트 연결 (최초 1회)
eas init

# 프로젝트 ID가 app.json의 extra.eas.projectId에 자동 설정됨
```

## Step 2: Android 프로덕션 빌드

```bash
# AAB (App Bundle) 빌드 - Play Store 제출용
eas build --platform android --profile production
```

빌드 ���료까지 약 10-20분 소요됩니다.  
완료되면 EAS 대시보드에서 `.aab` 파일을 다운로드합니다.

## Step 3: Google Play Console에서 앱 생성

1. https://play.google.com/console 접속
2. **"앱 만들기"** 클릭
3. 앱 정보 입력:
   - **앱 이름**: `이우고 코리아 - 중국 도매 직구`
   - **기본 언어**: ���국어
   - **앱 또는 게임**: 앱
   - **무료 또는 유료**: 무료
4. 개발자 정책 동의 체크 후 **"앱 만들기"**

## Step 5: 콘텐츠 등급 설정

1. Play Console → **정책** → **앱 콘텐츠** → **콘텐츠 등급**
2. IARC 설문 작성:
   - 폭력: 없음
   - 성적 콘텐츠: 없음
   - 도박: 없음
   - 약물: 없음
   - 사용자 생성 콘텐츠: 아니오 (리뷰는 있으나 모더레이션됨)
   - 구매: **예 (인앱 결제)**
3. 등급 결과 확인 후 적용

## Step 6: 개인정보처리방침

1. Play Console → **정책** → **앱 콘텐츠** → **개인정보처리방침**
2. URL 입력: `https://yiwugo.kr/privacy`
3. 데이터 안전 섹션 작성:
   - 수집 데이터: 이름, 이메일, 전화번호, 배송지, 결제정보
   - 공유 대상: 결제 대행사(토스페이먼츠), 물류 파트너
   - 보안 조치: 암호화 전송, 암호화 저장
   - ��제 요청: 가능 (설정 → 계정 삭제)

## Step 7: AAB 업로드 및 테스트

### 내부 테스트 (권장 - 먼저 진행)
1. Play Console �� **테스트** → **내부 테스트**
2. **"새 버전 만들기"** 클릭
3. `.aab` 파일 업로드
4. 버전 메모 작성
5. **"검토 시작"** 클릭
6. 테스터 이메일 추가 (최대 100명)

### 프로덕션 출시
1. 내부 테스트 확인 후 → **프로덕션** → **"새 버전 만들기"**
2. 내부 테스트 빌드를 프로모션하거나 새 AAB 업로드
3. **"프로덕션 출시 시작"** 클릭

## Step 8: EAS Submit으로 자동 제출 (선택)

```bash
# Google Play 서비스 계정 키 설정 후 자동 제출
eas submit --platform android --profile production
```

서비스 계정 키 생성 방법:
1. Google Cloud Console → IAM → 서비스 계정 생성
2. Play Console → 설정 → API 액세스 → 서비스 계정 연결
3. JSON 키 다운로드 → `apps/mobile/play-store-key.json`에 저장
